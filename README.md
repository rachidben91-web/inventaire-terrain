# Inventaire Terrain

Application HTML autonome pour realiser un inventaire terrain d'outillage.

## Fonctionnalites

- prise de photo d'un equipement
- OCR dans l'image via Tesseract.js
- selection de zones pour recuperer les informations utiles
- saisie et recapitulatif des elements inventoried
- export PDF
- export Excel

## Utilisation

1. Ouvrir `index.html` dans un navigateur moderne.
2. Prendre ou importer une photo de l'outil.
3. Lancer l'OCR et selectionner les zones utiles.
4. Completer les champs puis enregistrer les lignes d'inventaire.
5. Exporter le recapitulatif en PDF ou Excel.
